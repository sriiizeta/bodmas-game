# 🎮 BODMAS Game

An interactive web-based game designed to help students understand and practice **BODMAS (Order of Operations)** through engaging gameplay.

## 🚀 Features
- ⏱️ Timer-based gameplay  
- 🎯 Multiple levels with increasing difficulty  
- 💯 Score tracking system  
- 🧠 Focus on correct operator precedence (BODMAS)  
- 📱 Responsive and easy-to-use interface  

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  

## 🌐 Live Demo
https://bodmas-game-rosy.vercel.app/

## 📂 How to Run Locally
1. Download or clone the repository  
2. Open `index.html` in your browser  

## 📌 Description
This project demonstrates a simple and interactive approach to teaching mathematical concepts using visual and gamified learning techniques.
